A two-part micro-confession for make.fun's "Unsent: The Micro-Confession Sprint": a `To:` line naming who the message was meant for, and the one line that was typed and never sent — a spare key kept for two years because giving it back meant admitting someone wasn't coming back. The program prints the entry and writes it, with no trailing newline, to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

## Run it

```sh
node main.ts
```
